# Changelog

## 2.0.0

- Python rewrite of fiver as a terminal CLI
- Flag-style commands: `fiver --start`, `fiver --stop`, `fiver --status`, ...
- Intelligent server loop with wireless handoff and reconnect backoff
- One-line installer (`install.sh`) via pipx or user venv
- Docs for Android setup and troubleshooting
- GitHub project under https://github.com/Chintanpatel24/fiver
